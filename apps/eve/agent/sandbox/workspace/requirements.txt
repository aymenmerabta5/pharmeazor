# Python packages available inside the pharmeazor agent sandbox.
#
# The sandbox runtime is deliberately small: CPython plus the libraries needed
# to read the document formats a regulated pharmacy workflow produces. No
# numerical, scientific, cheminformatics, or machine-learning stack is
# installed, because the agent analyses documents rather than running models.
#
# Every distribution is pinned, including transitive dependencies, so a rebuilt
# sandbox image contains exactly the reviewed set of packages. The test in
# `apps/eve/tests/sandbox-contract.test.ts` fails when this file and the
# runtime contract in `agent/lib/sandbox-contract.ts` disagree.
#
# Update a pin, then rebuild the sandbox image before relying on the change.

# documents whose text layer pypdf cannot recover.
